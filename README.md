# Shooter2D · Сибирь и подбор пистолета

В тестовой сцене Сибирь подходит к лежащему у стены пистолету, наклоняется, берёт его за рукоять и выпрямляется. В игре персонаж отрисован 2D-спрайтами. Объёмная модель и скелет используются при подготовке кадров.

[Видео из кадров сборки](Docs/SibirPistolPickup/pistol-pickup-art-preview.mp4) · [Ключевые кадры](Docs/SibirPistolPickup/pistol-pickup-frames.png) · [Проверка геометрии](Docs/SibirPistolPickup/pistol-art-check.json)

## Как открыть сцену

1. Добавьте корень репозитория, где лежат `Assets`, `Packages` и `ProjectSettings`, в Unity Hub. Версия проекта указана в [ProjectVersion.txt](ProjectSettings/ProjectVersion.txt).
2. В Unity откройте [Assets/Scenes/PistolPickupTest.unity](Assets/Scenes/PistolPickupTest.unity) и нажмите **Play**.
3. Подойдите к пистолету и нажмите **E**. Попробуйте подойти слева, сверху и снизу. Для повторной проверки перезапустите Play.

## Что находится в сцене

```text
Player
├── Rigidbody2D / BoxCollider2D
├── PlayerMovement / PlayerInteraction / PlayerAttack
├── Sibir128Character
├── Sibir Sprite → SpriteRenderer
└── AimPivot
    └── FirePoint
PistolPickup → WeaponPickup / SpriteRenderer / Collider2D
Pistol Test Wall → BoxCollider2D
```

- **Player** задаёт положение тела и коллайдера в мире. Его точка опоры находится у ног персонажа.
- **Sibir Sprite** отображает силуэт. В редакторе виден кадр стойки из `PistolPickupTestIdle.png`. В Play его заменяют кадры атласа.
- **Sibir128Character** хранит привязки к `SpriteRenderer`, точке опоры, камере и начальному атласу `unarmed`. Другие наборы загружаются по имени из `Resources/Sibir128Looks`.
- **WeaponPickup** хранит ссылку на пистолет. Поле `Pistol Grip Local` задаёт место рукояти в локальных координатах лежащего спрайта. При перемещении или повороте объекта точка следует за ним.
- **Pistol Test Wall** нужна для проверки подхода со свободной стороны. Триггер лежащего пистолета подогнан под видимую часть спрайта.

## Как подготовлены кадры

1. Скрипт берёт сохранённые движения корпуса и ног из общих данных Сибиря. Углы ног рассчитываются на общем скелете с фиксированной длиной костей.
2. Подол рассчитывается по геометрии бёдер, голеней и верха сапог в каждой позе. Передняя часть подола может подниматься над ведущим коленом. Остальная часть тулупа сохраняет длину и силуэт.
3. Для подбора строятся позы от стойки без оружия до низкого наклона и подъёма. Рука, рукав, кисть и корпус участвуют в одной отрисовке. Для каждого кадра записывается экранная точка хвата относительно ног.
4. Поза проецируется ортографической камерой с высотой 60°. Кадры сохраняются в PNG-атласы с бинарной прозрачностью. У стойки, ходьбы и подбора общий масштаб 32 пикселя на единицу Unity и точка опоры **(56, 89)**.

| Набор | Направления | Фазы | Холст |
| --- | ---: | --- | --- |
| [Без оружия](Assets/Resources/Sibir128Looks/unarmed/sibir128.json) | 128 | Стойка и 8 фаз ходьбы | 112 × 112 |
| [С пистолетом](Assets/Resources/Sibir128Looks/pistol/sibir128.json) | 128 | Стойка и 8 фаз ходьбы | 112 × 112 |

Дополнительные прозрачные строки в подборе дают место вытянутой кисти при наклоне. Масштаб и положение ног сохраняются. Атлас содержит обрезанные кадры, а JSON хранит прямоугольник каждого кадра, его смещение и точку опоры. `Sibir128Character` создаёт `Sprite` из нужного прямоугольника и переиспользует его при повторе. Фильтрация Point сохраняет резкие пиксели. [Импорт текстур](Assets/Sibir128/Editor/Sibir128Tools.cs) · [Воспроизведение кадров](Assets/Sibir128/Runtime/Sibir128Character.cs)

### Стойка, поворот и ходьба

Направление взгляда привязано к курсору. Во время подбора его временно задаёт выбранный ракурс действия. Пройденное расстояние, рассчитанное по скорости `Rigidbody2D`, продвигает фазу шага. Смена направления и переключение атласов сохраняют фазу. Спрайт меняется целиком при сохранении точки опоры. Карта направлений учитывает вертикальное сжатие земли в наклонной проекции.

### Подход, захват и подъём

1. **Выбор предмета.** `PlayerInteraction` обрабатывает **E** и передаёт ближайший доступный пистолет в `PistolPickupSequence`.
2. **Выбор места для ног.** Для каждого из 32 направлений скрипт берёт смещение кисти в кадре захвата. Позиция ног равна мировой позиции рукояти минус это смещение с учётом масштаба персонажа. `Collider2D.Cast` проверяет проход телом, `Physics2D.Linecast` проверяет свободный отрезок до рукояти. Из подходящих мест выбирается ближайшее в пределах короткого шага.
3. **Подход.** `PlayerMovement` доводит персонажа до найденной позиции обычным движением. В этот момент воспроизводится ходьба. Перед наклоном управление сменой направления переходит к подбору.
4. **Захват.** Пистолет остаётся на полу до **12-го кадра**, который имеет индекс `11` в JSON. В этот кадр временный спрайт пистолета получает исходную позицию, поворот и масштаб предмета на полу. Тогда же оружие экипируется в игровой логике.
5. **Подъём.** Положение временного спрайта рассчитывается по точке хвата текущего кадра. Его рукоять следует за кистью. На последнем кадре включается атлас персонажа с пистолетом в руке и возвращается обычное управление.

## Как пересобрать спрайты

Исходники отрисовки находятся в [Tools/SibirPickup](Tools/SibirPickup). В папке `data` лежат профиль скелета, движение корпуса и ног, геометрия одежды, модель пистолета и контрольные положения руки. Данные Unity в `Assets` уже собраны, поэтому для запуска сцены Python не нужен.

На Linux с Python 3.14 установите зависимости и запустите генератор из корня репозитория.

```sh
python3 -m venv ../sibir-pickup-venv
. ../sibir-pickup-venv/bin/activate
python -m pip install -r Tools/SibirPickup/requirements.txt
OPENBLAS_NUM_THREADS=1 python -B Tools/SibirPickup/author.py --probe
OPENBLAS_NUM_THREADS=1 python -B Tools/SibirPickup/author.py
```

`--probe` проверяет геометрию поз без отрисовки атласов. Полный запуск обновляет атласы и кадр редактора в `Assets`, а отчёт и контактный лист сохраняет в `Docs/SibirPistolPickup`. Для проверки без перезаписи проекта задайте отдельные каталоги через `--asset-root` и `--report-root`. Если число страниц начального атласа изменится, обновите список `atlasPages` у `Sibir128Character` в сцене. Сохраняйте файлы `.meta` рядом с ассетами.

## Что проверено

- 3040 кадров атласов восстанавливаются из упакованных прямоугольников с теми же пикселями и точкой опоры. Отдельная пересборка из `Tools/SibirPickup` дала побайтно те же PNG и эквивалентные JSON-описания.
- На 41 позе объёмной модели проверены пары «ноги и подол», «правое предплечье и тулуп», «правая кисть и тулуп». Пересечений в этих пробах нет.
- Проверены расчёт всех 32 позиций захвата и тестовые подходы из трёх открытых сторон. C# скомпилирован, Unity импортировала сцену и атласы. Полный сценарий Play Mode остаётся отдельной проверкой.
